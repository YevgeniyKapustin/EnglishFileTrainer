# Экраны и стиль

Экраны, Settings, визуальный стиль. Основной план — `../PLAN.md`.

## Экраны (Navigation Compose)

**Язык — только английский** (решено 26.09.2026): весь интерфейс, инструкции,
правила (`Reference`), `hint`/`explain`, фидбек — по-английски. Переключателя
языка и русского перевода нет. Строки UI всё равно в `strings.xml`.


1. **Текущая глава** (стартовый) — разделы: открыт (% освоено) / закрыт (что откроет);
   внизу кнопка **Review** («повторение»), над ней одна строка «что будет»:
   «12 exercises from word order in questions» (+ «and 5 from earlier chapters»,
   если есть повторение).
2. **Раздел** — правила + задания в порядке книги, кнопка первого прохода.
   Каждое задание запускается отдельно (тап по строке → сессия только из него,
   «Done» — назад в раздел); кнопка внизу — весь раздел подряд.
3. **Упражнение** — один общий экран. Обвязка (прогресс сессии, «Проверить»,
   фидбек, «Далее») общая; `when (exercise)` выбирает composable ввода
   (`Rewrite` — поле на фразу, `Blank` — поля в тексте, `Speak`, `Talk`, `Write`). Это и есть «движок»:
   новая глава экранов не добавляет.
   Раскладки по `mockups/Exercises.html` (27.09.2026): `Task.words` — бирюзовая рамка над каждым пунктом,
   слово зачёркнуто, когда в этой сессии им верно ответили (только если слов не меньше пропусков задания);
   `Task.dialogue` — пузыри чата слева/справа по очереди, пропуски внутри; `Blank` вида «key: a, b, c → {}» —
   ключ крупно, варианты в рамке, поле ниже; неправильные глаголы — карточка с двумя полями; A/B в `Rewrite` —
   строки с буквами. `Speak` — только голосом, печатного ответа нет; «Skip» внизу убирает пункт из сессии
   без записи ответа (FSRS и прогресс не трогаются, пункт вернётся в следующий проход).
4. **Все главы** — список: пройденные (✓), текущая, будущие (закрыты). Только просмотр.
5. **Правила** раздела — таблица и 2–3 типичные ошибки; из раздела перед первым проходом.
6. **Итог сессии** — сколько с первого раза, прогресс главы, ошибки.
7. **Глава пройдена** — одна кнопка «Start 1B».
8. **Settings** (решено 26.09.2026) — шестерёнка справа вверху на текущей главе
   (слева «All chapters ›»). Три секции:
   - **Theme**: System / Light / Dark, у каждой цветная плитка-иконка (полукруг, солнце,
     луна), галочка у выбранной, применяется сразу. По умолчанию System.
   - **Voice** (озвучка реплик ИИ в разговоре; `VoiceSettings`, те же SharedPreferences, что у темы):
     «Read replies aloud» — выключатель, по умолчанию вкл.; выкл. — реплики сами не читаются, динамик у
     реплики работает. При вкл. ещё две строки: **Volume** — ползунок 0–100 % (по умолчанию 100,
     `KEY_PARAM_VOLUME` к каждой реплике, поверх громкости телефона) и **Speed** — Normal / Slow (≈ 0.8).
     Строка **Voice** (всегда, если есть синтезатор; нет — строки нет) — «Automatic» или «American · 2»,
     открывает экран выбора (`VoiceRoute`, `VoicePickerScreen`): «Automatic» (en-US, иначе en-GB), дальше
     английские офлайн-голоса из `getVoices()` (язык en, без сети, без `KEY_FEATURE_NOT_INSTALLED`)
     по акцентам (American / British / Australian / Indian / прочие — страна по-английски), «Voice 1, 2…»
     (номер по сортировке имён; системные имена не показываем). Тап — выбрать и прослушать фразу с текущими
     громкостью/темпом. Внизу «Get more voices» — `ACTION_INSTALL_TTS_DATA` движка по умолчанию, иначе
     `TTS_SETTINGS`, нет обоих — строки нет; по возвращении (ON_RESUME) список перечитывается. Храним
     `Voice.name` (`voice_name`); `Tts` ставит его `setVoice()` после инициализации, голоса нет или ошибка
     синтеза — молча Automatic (голос помечается сломанным до конца процесса).
   - **AI explanations**: одна строка «AI key» — **одно поле** для ключа любого из
     поддерживаемых: DeepSeek, OpenAI, Gemini, Claude, OpenRouter (под полем «Works with
     any of these:» и их логотипы). Провайдер определяется по виду ключа: `sk-ant-` →
     Claude, `sk-or-` → OpenRouter, `AIza` → Gemini, `sk-` + 32 hex → DeepSeek, прочие
     `sk-` → OpenAI; при сохранении ключ проверяется коротким запросом (у DeepSeek и
     старых ключей OpenAI начало одинаковое). Непохожий ключ — Save неактивна.
     Сохранён — у строки логотип провайдера и «On · Claude · …xyz»; Remove key.
     Модель не выбирается: у каждого провайдера зашита дешёвая и быстрая.

**Визуальный стиль — как в учебнике English File** (решено 26.09.2026). Всё рисуется
кодом, без картинок из книги (авторские права) и без стоковых иллюстраций
(Open Peeps пробовали — не подошли):
- **Шапка главы** — сине-бирюзовые клинья (как на развороте урока и в значке), большое
  белое «1A», два полупрозрачных облачка с хвостиками (как диалог) и репликами из урока («What do you do?» / «I'm at university.»);
  название главы — бирюзовым. У главы в контенте — пара реплик для облачков.
- **Веер по главе** — обведён с шапки SB (у всех 36 уроков одинаковый): 9 клиньев-«карточек» из одной точки над левым углом, дуги-концы, 8 ролей цвета из палитры File (4 по кругу: бирюза 1/5/9, жёлтая 2/6/10, зелёная 3/7/11, красная 4/8/12, `FilePalettes`); у каждой главы лёгкий сдвиг от книжного (`wedgeFan`: края ±2°, точка ±4%, радиусы ±2%); без главы — книжный File 1.
- **Метки разделов G / V / P** — цветные квадратики (Grammar синий, Vocabulary зелёный,
  Pronunciation розовый) + подпись капсом «GRAMMAR»; задания раздела — буквами a b c d.
- **Правила** — таблица в голубой плашке, заметка в бирюзовой рамке с лупой, типичные
  ошибки в зелёной плашке.
- **Итог сессии** и **Глава пройдена** — полоса с клиньями, счёт/следующая глава в облачке.
- **Все главы** — группы File 1 / File 2 …, номер главы в плашке цвета своего File.
- **Тёмная тема** — тёплая тёмно-серая (не чёрная), акценты те же, светлее.
- Логотипы ИИ-провайдеров — LobeHub Icons (MIT).

Как выглядит — `mockups/` (`plans/history.md`, Э0.5). Минимум текста: одно главное действие на экран.

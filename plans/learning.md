# Обучение

Освоение, FSRS, Review, открытие глав, свежие упражнения. Основной план — `../PLAN.md`.

## Как устроено обучение

Темп — **медленный и глубокий**: одна текущая глава, на ней сидим, пока не
освоим, хоть несколько уроков с учителем подряд. Отсюда два режима:

**Тренировка текущей главы** (основной режим):
- Первый проход по разделу — задания **в порядке книги**, блоками,
  с инструкцией сверху; перед ними — правила раздела (можно пропустить).
- Дальше «Тренировать главу» гоняет **неосвоенное** из открытых разделов текущей
  главы, без оглядки на даты. Неосвоенное — в приоритете, освоенное изредка
  подмешивается.
- **Освоено** = 3 верных ответа подряд, **в разные дни** (защита от
  «запомнил на 5 минут»). Неверный ответ сбрасывает серию. Повтор в тот же
  день (в т.ч. после ошибки и показа ответа) серию не двигает.
- **Глава пройдена**, когда на каждое упражнение книги был хотя бы один ответ (решено 27.09.2026, было «≥ 90 %
  освоено»). Тогда следующая становится текущей, пройденная уходит в повторение. Освоение — только для порядка
  в Review и процентов.
- Пункты из связного текста/диалога показываются вместе с `Task.context`,
  а не голой строкой.

**Повторение пройденного** (FSRS, ниже; решено 26.09.2026 вместо лесенки
Лейтнера): пройденные главы уходят в интервальное повторение. Кнопка **Review**
собирает сессию (~20): сначала due из пройденных глав (до 10, самое просроченное
первым), потом текущая глава из открытых разделов: неосвоенное (слабая серия
первой, новое в конце по книге) + освоенное не больше 1 из 5 мест. Отвеченное
сегодня в сессию не попадает — серия сегодня всё равно не вырастет.

**Кнопка на главном ведёт по дню** (решено 27.09.2026, `DayFlow.step`): вручную можно зайти в любую главу и раздел,
кнопка — только подсказка «что дальше». По порядку:
1. **Review** — пока есть due (пройденные главы, глаголы) или текущая глава с уже виденным, а законченной сессии
   Review сегодня ещё не было. Review на сегодня кончился = due и глаголов нет и сессия Review сегодня дошла до конца
   (или в текущей главе нечего повторять — всё новое). Дата последней законченной — `DaySettings.reviewedOn`.
2. **Continue <глава>** — актуальная глава: последняя выбранная вручную в «All chapters» (тап по любой;
   `DaySettings.chosenChapter`), иначе текущая. Если она пройдена не сегодня — следующая, и так дальше.
   Сессия — неотвеченное по книге, до 20 за раз.
3. **Practice <глава>** — глава, пройденная до конца сегодня (первый ответ на какое-то её упражнение — сегодня,
   по таблице `Answer`): сессии по 20 из всех её упражнений, неосвоенные и с худшим счётом (верно − неверно) первыми,
   по кругу до завтра. «Отвеченное сегодня» здесь не отсекается; серию освоения это не двигает — закрепление.
Главы для 2–3 нет (книга пройдена) — снова Review, если есть что; иначе кнопка неактивна.

**Неправильные глаголы** (решено 27.09.2026): весь список SB p.164 (PDF 165), 68 глаголов по книге,
`data/content/IrregularVerbs.kt` (руками, не через `generate.py`), id `iv-<глагол>` навсегда. Упражнение — `Blank`:
глагол, строки «past simple {}» и «past participle {}» (`\n` в `Blank.text` — перенос строки), верно только если
верны обе; варианты книги (learnt/learned, was/were) принимаются, у `can` только past simple. В Review — отдельным
блоком после due, **поверх** ~20 (`TrainingQueue.verbs`): due-глаголы (самый просроченный первым), затем новые по
книге — не больше 5 впервые отвеченных за день (впервые сегодня = `lastAnsweredOn` сегодня и один ответ всего),
всего не больше 10. Дальше — обычный FSRS. В главы, проценты, «Chapters» и слабые места Progress не входят.

```kotlin
@Entity
data class Progress(
    @PrimaryKey val exerciseId: String,
    val streak: Int,              // верных подряд в разные дни; >= 3 — освоено
    val stability: Double,        // FSRS: через сколько дней шанс вспомнить упадёт до 90%
    val difficulty: Double,       // FSRS: 1..10, насколько упражнение трудное для меня
    val dueOn: LocalDate,         // календарный день, не отметка времени
    val lastAnsweredOn: LocalDate,
    val correctCount: Int,
    val wrongCount: Int,
)

// Fsrs.kt — чистая функция, порт открытого FSRS (параметры по умолчанию, без обучения
// на своих данных). Ответ → оценка: неверно = Again, верно = Good.
fun next(exerciseId: String, current: Progress?, correct: Boolean, today: LocalDate): Progress
```

- Почему FSRS: у Лейтнера одинаковые интервалы для лёгкого и трудного; FSRS
  на каждое упражнение оценивает прочность памяти и трудность и назначает
  показ, когда шанс вспомнить падает до ~90% (`desiredRetention = 0.9`).
  Меньше лишних повторов, трудное не теряется. Стандарт в Anki с 2023.
- FSRS обновляем на **каждом** ответе (и в текущей главе тоже) — к моменту
  «глава пройдена» у упражнений уже честное состояние памяти. Но `dueOn`
  используется только для пройденных глав; текущая глава гоняется без дат.
- Упражнение без строки в базе = новое, доступно сразу.
- Потолок интервала — 180 дней, чтобы старое совсем не пропадало.
- День — календарный (`LocalDate`), чтобы повторы попадали в дневной ритм, а
  не зависели от часа ответа.
- Неверный ответ **внутри текущей сессии** дополнительно возвращается в конец
  очереди — это логика сессии, отдельная от FSRS.
- Прогресс пишем в Room сразу после каждого ответа, не в конце сессии.

- Открытие **автоматическое, без кнопок** (решено 26.09.2026, вместо ручного
  «Covered in class»):
  - все разделы главы открыты сразу, как в книге (решено 27.09.2026, было «по одному
    после первого прохода предыдущего»); Review гоняет первый раздел и начатые;
  - закрытых глав нет (решено 27.09.2026): в «All chapters» открыта и нажимается любая, тап только запоминает
    выбор для кнопки на главном. Досрочного открытия с предупреждением больше нет;
  - глава пройдена (`ChapterCompletion.isComplete`) = на каждое упражнение книги был ответ, в любом порядке глав.
    Строка `ChapterState` пишется при ответе и при старте (`Learning.syncCompleted`); старые строки остаются.
- Отдельной проверки ответов учителем в приложении **нет** (решено 26.09.2026):
  ответы `MODEL` идут в тренировку, «освоено» и повторение как обычные. Ошибку
  нейронки, если учитель её найдёт, правлю в JSON конвейера (`plans/pipeline.md`) → `CONFIRMED`.
- Флажка/списка «Спросить на уроке» в v1 **нет** (решено 26.09.2026) — вопросы
  по непонятному закрывает «Explain».

## Свежие упражнения на правило

- **Заготовки** вшиты в приложение, сочиняются в конвейере (`plans/pipeline.md` шаг 6), ключ ИИ не нужен: ~20 на раздел G/V,
  задания `"origin": "GENERATED"`, id `"<раздел>-x<N>"`, `source: MODEL`, у каждого `explain`.
  В модели — `Section.presets`; `Section.exercises` (первый проход, «освоено», «глава пройдена») их не содержит.
- **Сочинённое ИИ отдельно от учебника** (решено 27.09.2026): экраны глав и разделов показывают только оригинал книги;
  заготовки и `-gen-` — только в Review, когда книга раздела освоена; заготовки раньше ИИ (`TrainingQueue.freshOf`).
  У всех (G/V/PE) инструкция с пометкой «Fresh practice: …» (`Chapters.locate`).
- **ИИ** (`Generation.kt`, Room `GeneratedExercise`, id `"<раздел>-gen-NNNN"`) — добавка, когда все заготовки
  раздела уже встречались. Промпт получает правила раздела, лексику главы и задания книги как образец.
  После неудачи ИИ — пауза 1 мин. Досочинённое во время Review сразу встаёт в конец текущей сессии
  (`Generation.fresh` → `TrainingQueue.arrivals`, не больше `FRESH_ARRIVALS` = 5 за сессию).
- Проверка: `generate.py` `validate_presets` и `ContentValidationTest` — MODEL, explain, только Rewrite/Blank,
  ответы проходят `Checker`, нет повторов с книгой и между собой.

# Релиз: подписка на ИИ-функции

Идея от 27.09.2026. Основной план — `../PLAN.md`.

Сейчас приложение личное. Если выпускать для других с платной подпиской на ИИ — отдельный этап, по шагам:

1. **Контент — решить первым, до любых денег.** Упражнения, аудио и видео English File — Oxford University Press;
   продавать приложение с ними нельзя (даже если платно только ИИ). Варианты: лицензия издательства
   (для частного проекта почти нереально) или **свой контент** — движок, FSRS, проверка, ИИ остаются, главы
   заменяются своими по темам уровня (упражнения сочиняет модель, озвучка — синтез речи). Это уже
   «грамматический тренажёр по уровню», а не «по English File»; личная сборка с книгой может жить отдельно.
2. **Сервер** (из `PLAN.md` §0 «Планы», но сразу «по-взрослому»): вход пользователя (например, Google), проверка подписки,
   лимит запросов в день на пользователя, прокси к провайдеру — ключ только на сервере, в приложение не отдаётся.
   Хватит бессерверного (Cloudflare Workers / Supabase).
3. **Оплата:** в Google Play — только Play Billing (комиссия 15%); вне Play (APK, RuStore) — ЮKassa,
   CloudPayments или биллинг RuStore. Для приёма денег — самозанятость или ИП.
4. **Бумаги:** политика конфиденциальности, условия использования (Play без них не пропустит); сверить условия
   API провайдера (DeepSeek/OpenAI платный продукт поверх API разрешают).
5. **Экономика:** запрос к DeepSeek — доли цента; при подписке ~200–300 ₽/мес маржа большая, если есть лимиты.

Без подписки ИИ по-прежнему отключаемый: всё офлайн-обучение работает бесплатно.
